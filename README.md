# Digital Pompeii

### *一个自治的链上验尸官与陨落协议博物馆*

> 一座去中心化废墟博物馆，收藏那些死于贪婪、漏洞、缺陷与背叛的项目。

Digital Pompeii 是一个自治的取证型 AI 系统，会直接基于不可篡改的链上证据调查已经死亡的区块链项目。

只需要给定一个合约地址，Agent 就会独立读取已验证的智能合约代码、追踪关键交易、形成并修正假设、交叉审验证据，最终生成一份结构化的取证展品：一半是技术验尸报告，一半是数字墓志铭。

每一次崩塌，都会成为永久的废墟。
每一次攻击，都会成为刻入历史的警示。

# I. 为什么这很重要

在 Web2 中，失败的公司会消失在公关声明、被删除的帖子和被遗忘的时间线之后。

链上系统则不同。

即使崩塌之后，尸体依然存在：

* 智能合约
* 交易
* 所有权转移
* 攻击痕迹
* 流动性抽离

区块链保存了一切。

Digital Pompeii 的存在，是为了把这些永久废墟转化为公共记忆。

## 公共价值

每一个被调查的协议都会成为：

* 可复现的取证档案
* 给未来建设者的警示纪念碑
* 面向生态系统的教育案例

我们相信，去中心化系统也应该保存去中心化的历史记忆。

---

# II. 与众不同之处

Digital Pompeii **不是**：

* 静态 AI 报告生成器
* 区块链浏览器封装层
* 预先写好的内容流水线

项目的核心是一个由 GLM-5.1 驱动的**自治取证 Agent**。

Agent 不会接收预先包装好的结论。

相反，它会独立地：

1. 调查
2. 形成假设
3. 搜索证据
4. 寻找矛盾
5. 修正结论
6. 生成最终取证展品

文学化表达只会在技术调查完成之后生成。

> 设计原则：
> 事实在先，文学在后。
>
> 不虚构技术结论。
> 每一个结论都必须能够追溯到可验证的链上证据。

# III. 工作方式

## 调查工作流

```text
输入：合约地址
   │
   ▼
① 现场勘验
   ─ 获取已验证源码与元数据

② 代码验尸
   ─ 分析权限、可升级性、可疑逻辑、
     缺失校验、危险所有权模式

③ 血流追踪
   ─ 追踪关键交易与资金流向

④ 假设生成
   ─ 推断可能的死亡原因

⑤ 反证搜索
   ─ 主动寻找矛盾证据与替代解释

⑥ 假设修正
   ─ 基于证据冲突细化结论

⑦ 案件结案
   ─ 生成结构化取证展品
```

# V. 长周期自治推理

本项目被有意设计为一个长周期自治任务。

单次调查可能需要：

* 多轮工具调用
* 假设修正
* 证据对齐
* 交易追踪
* 矛盾处理

Agent 会在整个过程中维护调查状态，而不是生成一次性的回答。

## 调查状态

Agent 会持续更新：

* 观察结果
* 可疑函数
* 交易证据
* 已否定的假设
* 置信度
* 替代解释

这让系统能够进行真正的取证推理，而不是简单完成提示词。

---

# VI. 自我修正与假设系统

Digital Pompeii 的一个关键特性是：Agent 会主动怀疑自己。

示例：

```text
初始假设：
重入攻击

新证据：
未检测到递归抽干模式

修正后假设：
所有者通过特权提现进行 Rug Pull
```

系统会显式追踪：

* 支持某项主张的证据
* 反证
* 不确定性
* 置信度分数

如果证据不足，Agent 会将结论标记为：

> “不确定 / 无法定论”

而不是幻觉式地给出确定答案。

# VII. 展品输出结构

每一次调查都会生成一份结构化的展品 JSON。

## 技术验尸层

冷静、基于证据的取证发现：

* 死亡原因
* 关键交易
* 攻击时间线
* 可疑函数
* 预估损失
* 证据引用
* 置信度分数
* 替代假设

## 策展叙事层

调查完成之后撰写的文学墓志铭：

* 历史叙事
* 悲剧框架
* 工程警示
* 哲学反思

每一条文学化表述都必须对应已验证的技术证据。

# IX. GLM-5.1 使用方式

## 运行时

后端 Agent 运行时使用：

* GLM-5.1
* OpenAI 兼容 API 接口
* 迭代式工具调用循环

## 模型职责

GLM-5.1 会自治决定：

* 调用哪个工具
* 检查哪些证据
* 证据是否充分
* 何时修正假设
* 何时可以结案

这不是固定脚本流水线。

模型本身控制调查过程。

# XII. 安全与权限边界

## 只读系统

Digital Pompeii：

* 永不写入链上
* 永不持有私钥
* 永不连接钱包
* 永不发起交易

系统只读取公开区块链数据。

## 风险声明

本项目提供：

* 取证分析
* 风险信号
* 历史解释

它**不**保证安全性或正确性。

所有发现都应接受人工复核。

---

# XIII. 为什么 Web3 在这里重要

区块链让永久的历史记忆成为可能。

不同于 Web2：

* 交易无法被删除
* 攻击痕迹始终可见
* 所有权历史永久保留

Digital Pompeii 将不可篡改的区块链数据转化为不可篡改的文化记忆。

可选：

* 使用 OpenTimestamps 锚定展品完整性验证
